## 二、目录职责速查

| 目录 | 一句话 | 放什么 | 不放什么 |
|------|--------|--------|---------|
| `django_edu_manage/` | 项目配置中心 | settings, urls, wsgi, 中间件 | 业务逻辑、Model、API 视图 |
| `django_edu_manage/common/` | 响应/异常/日志基础设施 | response, renderer, exceptions | 业务权限、分页、工具函数 |
| `apps/core/` | 全局基础设施 | pagination, permissions, routers | 具体业务逻辑 |
| `apps/auth/` | 认证 | LoginView, RegisterSerializer | 用户 CRUD、审核（那是 users 的事） |
| `apps/users/` | 用户管理与审核 | User 模型, UserViewSet, 审核 | 认证逻辑（那是 auth 的事） |
| `apps/dicts/` | 基础字典（四合一） | SubjectDict, SemesterDict, ResearchGroupDict, ClassDict | 业务逻辑 |
| `apps/user_profile/` | 师生档案 | TeacherProfile, StudentProfile | 用户认证、字典数据 |
| `apps/exam/` | 考试管理 | 考试计划 CRUD、name 自动生成 | 成绩存储（那是 score 的事） |
| `apps/score/` | 成绩记录 | 学生/考试/科目绑定与分数存储 | 考试元数据（那是 exam 的事） |
| `apps/dashboard/` | 统计聚合 | 跨表查询、数据汇总 | 原始数据 CRUD |

### 数据流向（以考试列表为例）

```
GET /api/exams
  → urls.py 匹配 ExamPlanViewSet
    → permission_classes 鉴权（JWT → IsAuthenticated）
      → queryset 查询（exam.models.ExamPlan，select_related 预取学期）
        → serializer 序列化（exam.serializers.ExamPlanSerializer）
          → UnifiedJSONRenderer 包裹（common.renderer）
            → 分页处理（core.pagination）
              → JSON 响应
```

### 模型之间的关联

```
User (users)
  ├── 1:1 → TeacherProfile (user_profile)
  │           ├── M2M → ResearchGroupDict (dicts)
  │           └── M2M → ClassDict (dicts)
  └── 1:1 → StudentProfile (user_profile)
                └── FK → ClassDict (dicts)

ClassDict (dicts)
  ├── FK → TeacherProfile (headmaster/班主任)
  └── 被 StudentProfile.class_id 引用

ExamPlan (exam)
  ├── FK → SemesterDict (dicts)
  └── grade 使用 GradeChoices 枚举（与 ClassDict.grade 共用）

Score (score)
  ├── FK → StudentProfile (user_profile)
  ├── FK → ExamPlan (exam)
  ├── FK → SubjectDict (dicts)
  └── UniqueConstraint(student, exam, subject)

dashboard 不建表，只做聚合查询：
  DashboardStatsView → StudentProfile / TeacherProfile / ClassDict / ResearchGroupDict
```

## 五、当前项目的最佳实践

### 5.1 已经在用的好做法

| 实践 | 说明 |
|------|------|
| **Settings 拆分** | `base/development/production` 三个文件，环境隔离清晰 |
| **django-environ** | 环境变量优先级：`.env` → `.env.{env}` → `.env.local` → 系统变量 |
| **统一响应格式** | `ApiResponse` + `UnifiedJSONRenderer`，前端拿到的 JSON 结构永远一致 |
| **JWT + 黑名单** | 无状态认证 + refresh token 轮转 + 登出黑名单 |
| **认证与用户管理分离** | `apps/auth/` 只管认证流程，`apps/users/` 只管用户 CRUD 和审核 |
| **字典模块四合一** | 科目/学期/教研组/班级合入 `apps/dicts/`，减少 app 碎片化 |
| **NoSlashRouter** | 自定义 Router 去掉路由末尾斜杠，配合 `APPEND_SLASH=False` |
| **ViewSet + APIView 混用** | 标准 CRUD 用 ModelViewSet，复杂逻辑用 APIView |
| **Serializer 做响应文档** | Dashboard 无 Model 也用 Serializer 声明响应结构 |
| **核心模块分离** | `apps/core/` 存放跨 app 复用的基础设施（分页、权限、路由） |
| **字符串外键引用** | `'dicts.ResearchGroupDict'` 避免循环导入 |
| **Data Migration** | 种子数据写为 migration，`migrate` 即自动填充，环境一致性 |
| **related_name 显式命名** | 避免 Django 自动生成的反向名冲突 |
| **select_related 预取** | ViewSet.queryset 中预取 FK 关联，减少 N+1 查询 |

### 5.2 编码约定

- **Model**：单数命名（`ClassDict` 而非 `Classes`，`SubjectDict` 而非 `Subject`），加 Dict 后缀区分字典表
- **Serializer**：`{Model}Serializer` 或 `{用途}Serializer`
- **ViewSet**：`{Model}ViewSet`
- **URL**：RESTful 复数形式（`/api/classes`、`/api/subjects`），无末尾斜杠
- **权限**：`permission_classes` 列表，`IsAuthenticated` 放前面
- **注释**：解释 WHY 而非 WHAT，代码自解释
- **表名**：字典表统一 `dict_` 前缀（`dict_subject`、`dict_semester`、`dict_class`、`dict_research_group`）

## 六、新建模块清单

新增一个业务模块需要创建以下文件：

```
apps/new_module/
├── __init__.py
├── apps.py          # class NewModuleConfig(AppConfig): name = 'apps.new_module'
├── models.py        # 数据库模型（没有表就跳过）
├── serializers.py   # 序列化器
├── views.py         # ViewSet 或 APIView
├── urls.py          # 路由注册
├── admin.py         # Django Admin 注册（按需）
└── tests.py         # 测试用例
```

然后在以下位置注册：
1. `django_edu_manage/settings/base.py` → `INSTALLED_APPS` 加 `'apps.new_module.apps.NewModuleConfig'`
2. `django_edu_manage/urls.py` → 加 `path('api/', include('apps.new_module.urls'))`
