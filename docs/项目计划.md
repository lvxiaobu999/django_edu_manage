# 项目计划


## 考试模块

添加一个考试计划模块（exam）
这就是你要找的“月考名称、时间段”的载体。我们不把考试信息直接挂在成绩表里，而是建立一个独立的“考试实体”。这样即使名字都叫“第一次模拟考”，只要它们属于不同的学期或日期，在数据库里就是两条互不干扰的独立记录。

字段名          字段类型             描述

name           CharField           考试名称（如：“2026春季高一第一次月考”）

exam_type      CharField           考试类型枚举（如：MONTHLY月考, MOCK模拟考, MIDTERM期中考, 

FINAL 期末考）

exam_date      DateField           具体的考试日期

grade	       CharField	       所属年级 枚举值 GradeChoices

semester	   CharField	     管理学期字典表

## 成绩记录表模块 (score) —— 核心枢纽

这张表是整个业务的十字路口，它将你的学生、考试和科目精准地绑定在一起。

字段名	 字段类型	 关联关系	            描述

student	ForeignKey	关联 StudentProfile	  明确是哪个学生的成绩。还记得我们在 StudentProfile 里设计了指向所在班级的 class_id 外键吗 ？通过这层关联，系统天然就能知道这笔成绩属于哪个年级哪个班。

exam	ForeignKey	关联 ExamPlan	      明确是哪次特定的考试。

subject	ForeignKey	关联 SubjectDict	  明确是哪一门学科。

score	DecimalField	无	              实际分数（推荐使用 Decimal 保留两位小数，比如 99.50，以应对半分布分的


## 学期字典模块（semester_dict）

把学期独立成表后，你不仅可以用来做查询条件，还可以加入几个“杀手级”字段，让系统变得异常智能：

字段名	字段类型	描述	架构师建议
name	CharField	学期名称	比如：“2025-2026学年上学期”
start_date	DateField	开学日期	方便后期按时间段统计数据
end_date	DateField	放假日期	同上
is_current	BooleanField	是否当前学期	核心推荐！ 默认 False。这样前端默认只需要请求 is_current=True 的学期，直接展示最新的考试和成绩，极大提升用户体验。
