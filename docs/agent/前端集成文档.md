## 一、前端依赖

不需要任何 LangChain 或 AI 专用库。AI 能力完全由后端封装，前端只需要：

| 包名 | 用途 | 可选性 |
|------|------|--------|
| `axios` 或 `fetch`（浏览器原生） | HTTP 请求 | **必选** |
| `uuid` 或 `nanoid` | 生成 session_id（多轮对话用） | 推荐 |
| `react-markdown` | 渲染 AI 返回的 Markdown 格式回答 | 推荐 |

### 安装推荐依赖

```bash
npm install axios react-markdown nanoid
# 或
pnpm add axios react-markdown nanoid
```

## 二、API 接口一览

所有接口基础路径：`http://127.0.0.1:8000`（开发环境）

### 统一响应格式

```json
{
  "success": true,
  "code": 0,
  "message": "查询成功",
  "data": {
    "answer": "..."
  },
  "meta": {
    "requestId": "uuid",
    "timestamp": "2026-06-24T08:00:00+00:00"
  }
}
```

- `success: true` → `data.answer` 中是 AI 回答文本
- `success: false` → `message` 中是错误描述，`code` 是业务错误码

### 认证方式

所有 AI 接口需要 **JWT Bearer Token**——先调用登录接口，后续请求在 Header 中带上 token：

```
Authorization: Bearer <access_token>
```

### 2.1 单次问答（无记忆）

```
POST /api/agent/chat
```

每次请求都是独立的，AI 不记得上一轮说了什么。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户提问，最多 2000 字符 |

**请求示例：**

```bash
curl -X POST http://127.0.0.1:8000/api/agent/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"query": "海南中学是哪一年成立的？"}'
```

**成功响应：**

```json
{
  "success": true,
  "code": 0,
  "message": "查询成功",
  "data": {
    "answer": "海南中学成立于**1923年秋**，最初由钟衍林、冯官尧等教育工作者筹建，定名为「私立琼海中学」……"
  }
}
```

### 2.2 多轮对话（带记忆）

```
POST /api/agent/chat/session
```

同一 `session_id` 共享对话历史，AI 能理解上下文指代。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户提问，最多 2000 字符 |
| `session_id` | string | 是 | 会话标识，同一会话保持一致 |

**请求示例：**

```bash
# 第一轮
curl -X POST http://127.0.0.1:8000/api/agent/chat/session \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"query": "海南中学哪年成立？", "session_id": "abc-123"}'

# 第二轮 —— AI 知道"它"指海南中学
curl -X POST http://127.0.0.1:8000/api/agent/chat/session \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"query": "它的校训是什么？", "session_id": "abc-123"}'
```

---

### 2.3 清除会话记忆

```
DELETE /api/agent/chat/session
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 要清除的会话标识 |

## 三、React 代码示例

### 3.1 API 封装层 (`api/agent.ts`)

```ts
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://127.0.0.1:8000/api',
});

// 请求拦截：自动注入 token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截：token 过期自动刷新
api.interceptors.response.use(
  (res) => res,
  async (error) => {
    if (error.response?.status === 401) {
      // 重定向登录页
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

// ==================== AI Agent 接口 ====================

/** 单次问答（无记忆） */
export async function chat(query: string): Promise<string> {
  const { data } = await api.post('/agent/chat', { query });
  if (data.success) return data.data.answer;
  throw new Error(data.message);
}

/** 多轮对话（带记忆） */
export async function chatSession(query: string, sessionId: string): Promise<string> {
  const { data } = await api.post('/agent/chat/session', {
    query,
    session_id: sessionId,
  });
  if (data.success) return data.data.answer;
  throw new Error(data.message);
}

/** 清除会话记忆 */
export async function clearChatSession(sessionId: string): Promise<void> {
  await api.delete('/agent/chat/session', {
    data: { session_id: sessionId },
  });
}
```

### 3.2 聊天组件 (`ChatPanel.tsx`)

```tsx
import { useState, useRef } from 'react';
import ReactMarkdown from 'react-markdown';
import { nanoid } from 'nanoid';
import { chat, chatSession, clearChatSession } from '../api/agent';

interface Message {
  role: 'user' | 'assistant';
  content: string;
}

export default function ChatPanel() {
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState('');
  const [loading, setLoading] = useState(false);

  // 多轮对话模式用的 sessionId（首次发送时生成）
  const sessionRef = useRef<string>('');

  const send = async () => {
    if (!input.trim() || loading) return;

    const query = input.trim();
    setInput('');

    // 1. 把用户消息追加到列表
    setMessages((prev) => [...prev, { role: 'user', content: query }]);
    setLoading(true);

    try {
      // 2. 调用后端
      const answer = sessionRef.current
        ? await chatSession(query, sessionRef.current)   // 多轮模式
        : await chat(query);                              // 单次模式

      // 3. 把 AI 回答追加到列表
      setMessages((prev) => [...prev, { role: 'assistant', content: answer }]);
    } catch (err: any) {
      setMessages((prev) => [
        ...prev,
        { role: 'assistant', content: `❌ 错误：${err.message}` },
      ]);
    } finally {
      setLoading(false);
    }
  };

  const startNewSession = () => {
    if (sessionRef.current) {
      clearChatSession(sessionRef.current).catch(() => {});
    }
    sessionRef.current = nanoid();
    setMessages([]);
  };

  return (
    <div className="chat-panel">
      <div className="chat-header">
        <h2>🤖 AI 助手</h2>
        <button onClick={startNewSession}>新建会话</button>
      </div>

      <div className="chat-messages">
        {messages.map((msg, i) => (
          <div key={i} className={`message ${msg.role}`}>
            <strong>{msg.role === 'user' ? '你' : '🤖 助手'}</strong>
            <ReactMarkdown>{msg.content}</ReactMarkdown>
          </div>
        ))}
        {loading && <div className="typing">AI 正在思考…</div>}
      </div>

      <div className="chat-input">
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && send()}
          placeholder="输入问题，如「海南中学哪年成立？」"
          disabled={loading}
        />
        <button onClick={send} disabled={loading}>
          发送
        </button>
      </div>
    </div>
  );
}
```

### 3.3 快速接入（最简版）

如果你只需要一个最简的问答功能（不用 Markdown 渲染、不用多轮对话）：

```tsx
// 一行接口调用
const [answer, setAnswer] = useState('');

async function ask(query: string) {
  const res = await fetch('http://127.0.0.1:8000/api/agent/chat', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${localStorage.getItem('access_token')}`,
    },
    body: JSON.stringify({ query }),
  });
  const json = await res.json();
  setAnswer(json.data.answer);
}

// 使用
<button onClick={() => ask('海南中学是哪一年成立的？')}>询问</button>
<pre>{answer}</pre>
```

## 四、接口选型指南

| 场景 | 使用接口 | session_id |
|------|----------|------------|
| 首页一个问答框，用户单次提问 | `POST /api/agent/chat` | 不需要 |
| 聊天面板，用户可以追问 | `POST /api/agent/chat/session` | 用 `nanoid()` 生成 |
| 用户点了"新建会话" | `DELETE /api/agent/chat/session` | 传旧的，然后生成新的 |

## 六、常见问题

**Q：接口返回 401？**  
A：JWT token 过期或未传。检查 `Authorization: Bearer <token>` 是否正确，确认登录接口返回的 access token 有效。

**Q：多轮对话中 AI 忘了上下文？**  
A：确认每次请求的 `session_id` 相同。会话记忆保留 10 轮，超出后最早的消息自动丢弃。

**Q：响应很慢？**  
A：首次请求会初始化 RAG 向量索引（约 1-2 秒），后续请求正常。如果持续慢，检查 OpenAI API 的网络延迟。

**Q：想扩展知识库内容？**  
A：直接编辑 `apps/agent/学校简介.md`，重启服务后新内容自动生效（首次查询时重建向量索引）。
